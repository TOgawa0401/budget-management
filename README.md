\# データ推進部 2026年度予算管理 - Phase 2



Google Sheets + Google Apps Script + React を使用した予算管理アプリケーション



\## 機能

\- リアルタイム同期（5分ごとに自動同期）

\- 複数ユーザー対応

\- CRUD 操作（追加・編集・削除）
